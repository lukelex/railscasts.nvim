## Highlights

- Added native Kmonad `.kbd` filetype detection and syntax highlighting.
- Added aligned terminal profiles for Ghostty, Windows Terminal, and iTerm2.
- Added parser-backed language coverage for Nix, Clojure, Kotlin, Swift, Zig,
  and Dart.
- Expanded Vue and Svelte embedded-template fixtures and regenerated the visual
  gallery with the new language and workflow examples.

## Compatibility

The new language support uses the existing Railscasts semantic roles and keeps
Neovim 0.9.5 as the minimum supported version.

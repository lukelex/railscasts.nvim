## Highlights

- Added `:checkhealth railscasts` to verify Neovim support, true-color mode,
  active Railscasts options, and the ANSI terminal palette.
- Added the opt-in `darker_background` surface option alongside transparent
  mode.
- Expanded formal highlighting and parser-backed fixture coverage for Git
  workflows, man pages, help files, HCL, templates, Elixir, Erlang, GraphQL,
  Protocol Buffers, and additional popular languages.

## Configuration

Use `darker_background = true` for a `#1F1F1F` solid Railscasts surface. It is
intentionally mutually exclusive with `transparent = true`.
